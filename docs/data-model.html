Property agent domain

One agent manages many rental properties. Each property is occupied by a single family and has one or more tenants from that family. The agent keeps notes and reminders so they can carry out work such as maintenance and pest control.

PK primary key FK foreign key UK unique key Crow’s foot = many  ·  bar = one

Integrity rules

  • An agent may manage many properties. A property has exactly one agent. The in-memory API still allows deleting an agent; leftover properties keep the old agent_id.
  • Each property is occupied by exactly one family, and must have one or more tenants. Every tenant on that property must share the property’s family_id.
  • Property notes and reminders are owned by the agent and point at a property. action_type is any non-empty string up to 50 characters (built-ins plus custom). A separate agent-only notes API has no property_id.
  • Every table carries created_at and updated_at. Email on agents is unique.
